# Лабораторная работа 1: Моделирование движения объекта по связи

Этот проект представляет собой программную реализацию лабораторной работы по дисциплине **«Программные средства для научных расчетов и обработки экспериментальных данных»**. Он моделирует движение шарика по дуге окружности под действием силы тяжести с учетом вязкого трения.



## Описание задачи

**Цель проекта** — получить уравнения движения объекта, ограниченного движением по заданной кривой (в данном случае — дуга окружности), с учетом силы вязкого трения, и решить их численно с помощью различных методов.

Проект включает:

- Реализацию методов Эйлера и Хьюна (опционально — метод Рунге-Кутты 4-го порядка).
- Сравнение решений, полученных разными методами.
- Построение графиков:
  - Координат `x(t)`, `y(t)`
  - Проекций скоростей `vx(t)`, `vy(t)`
  - Траектории движения `y(x)` (или `x(y)`)
- Анимацию движения объекта на плоскости `xy`.



## Уравнения движения

Уравнения движения получены с использованием уравнений Лагранжа первого рода с неопределенным множителем Лагранжа `λ`, описывающим реакцию связи (силу натяжения нити).

### 1. Кинетическая и потенциальная энергия:

- **Кинетическая энергия**:  
  `T = 1/2 * m * (vx² + vy²)`

- **Потенциальная энергия** (сила тяжести, ось `y` направлена вниз):  
  `U = m * g * y`

### 2. Уравнение связи:

Для движения по окружности радиуса `R` с центром в начале координат:  
`f(x, y) = x² + y² - R² = 0`

### 3. Система уравнений движения:

Следуя алгоритму из лекции (стр. 9), получаем систему ОДУ второго порядка:

```
m * x'' = -λ * x - b * x'
m * y'' = -m * g - λ * y - b * y'
x² + y² = R²
```


С выражением для `λ`:
```
λ = (m * (vx² + vy²) - m * g * y) / R²
```




## Численные методы

Проект реализует следующие численные методы для интегрирования системы ОДУ:

### 1. Метод Эйлера

Простейший одношаговый метод:


```
y_{n+1} = y_n + h * f(t_n, y_n)
```



Использует наклон в начале интервала для оценки решения в конце.

### 2. Метод Хьюна (предиктор-корректор)

Более точный метод:

- **Предиктор**: оценка методом Эйлера.
- **Корректор**: уточнение с использованием среднего значения производных:

```
y_{n+1} = y_n + h/2 * (f(t_n, y_n) + f(t_{n+1}, y_{n+1}^pred))
```


### 3. Метод Рунге-Кутты 4-го порядка (опционально)

Высокоточный метод, использующий взвешенное среднее четырех оценок производной в разных точках интервала.

Программа генерирует следующие результаты:

  Сохраняются в файл `results/simulation_results.png`.

## Выводы

Сравнение решений, полученных разными методами (с шагом `dt=0.05` и `dt=0.005`), позволяет сделать следующие выводы:

- **Точность**:  
  Метод Хьюна значительно точнее метода Эйлера. Метод Рунге-Кутты 4-го порядка обеспечивает наивысшую точность.

- **Зависимость от шага**:  
  Уменьшение шага интегрирования (`dt`) увеличивает точность для всех методов. Разница особенно заметна для метода Эйлера.

- **Эффективность**:  
  Метод Эйлера — самый быстрый, но наименее точный. Методы Хьюна и Рунге-Кутты требуют больше вычислений на шаг, но позволяют достигать высокой точности даже с бо́льшими шагами.
