# Лабораторная работа 1: Моделирование движения объекта по связи

Программная реализация лабораторной работы по дисциплине **«Программные средства для научных расчетов и обработки экспериментальных данных»**: движение материальной точки по заданной кривой **f(x, y) = 0** под действием силы тяжести и вязкого трения (коэффициент `b` можно задать нулём).

## Описание задачи

**Цель** — численно решить уравнения движения с голономной связью и сравнить методы интегрирования.

Проект включает:

- Методы Эйлера, Хьюна и Рунге-Кутты 4-го порядка.
- Сравнение решений на одном интервале времени.
- Графики `x(t)`, `y(t)`, `vx(t)`, `vy(t)`, траектория на плоскости `xy`.
- Анимацию в окне PyQt6 с отрисовкой контура связи.

## Уравнения движения

Используются уравнения Лагранжа первого рода с множителем `λ` (реакция связи).

### Энергия

- **Кинетическая**: `T = (m/2)(vx² + vy²)`
- **Потенциальная** (ось `y` вниз): `U = m g y`

### Уравнение связи

`f(x, y) = 0.5·x² + y² + 0.5·x·y − 4y = 0`

Частные производные: `fx = x + 0.5y`, `fy = 0.5x + 2y − 4`.

### Система в форме ОДУ

С учётом вязкого трения:

```
m·x'' = λ·fx − b·vx
m·y'' = −m·g + λ·fy − b·vy
```

Условие удержания на связи `d²f/dt² = 0` при `f = 0` и `fx·vx + fy·vy = 0` даёт

`H = vx² + vx·vy + 2·vy²`,

```
λ = m·(g·fy − H) / (fx² + fy²)
```

Начальное положение должно лежать на связи, а скорость — быть касательной к ней (`∇f·v = 0`). Пример из варианта: точка `(0, 4)` и нулевая скорость.

## Численные методы

Реализованы в [`utils/solvers.py`](utils/solvers.py): **EulerMethod**, **HeunMethod**, **RungeKutta4Method** (одинаковый интерфейс `solve(...)`).

При одном и том же шаге `dt` метод Хьюна обычно точнее Эйлера; RK4 даёт наиболее точное эталонное решение при мелком шаге. Уменьшение `dt` уменьшает дрейф от связи у явного метода Эйлера; для отчёта полезно сравнивать кривые и невязку `f(x, y)` у разных методов.
