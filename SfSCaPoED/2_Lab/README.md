# Лабораторная работа 2: экспериментальные траектории и доверительные интервалы

Окно на **PyQt6** + **matplotlib**. Та же механическая модель, что в ЛР1 ([`utils/model.py`](utils/model.py) — связь, тяжесть, вязкое трение). Теоретическая траектория считается **одним** прогоном **RK4** с шагом `dt` из формы. К ней добавляется шум; по реализациям строятся среднее и **двусторонний 95% доверительный интервал** для среднего по **распределению Стьюдента**.

## Запуск

```bash
cd SfSCaPoED/2_Lab
pip install -r requirements.txt
python main.py
```

Если видите `ModuleNotFoundError: scipy`, установите пакет **в том же окружении**, откуда запускаете `python` (например `study_env`): `pip install scipy`. Без scipy программа всё равно запустится для **N = 5** и **N = 25** при доверительной вероятности 95% (зашиты квантили t для df = 4 и 24).

## Структура

- [`utils/experiment.py`](utils/experiment.py) — шум, ансамбль, среднее и ДИ.
- [`utils/gui/model.py`](utils/gui/model.py) — интегрирование и сборка данных для графиков.

Для отчёта выполните расчёт отдельно при **N=5** и **N=25** (выбор в комбобоксе), при необходимости сохраните скриншоты.
