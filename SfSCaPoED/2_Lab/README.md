# Лабораторная работа 2: экспериментальные траектории и доверительные интервалы

Окно на **PyQt6** + **matplotlib**. Та же механическая модель, что в ЛР1 ([`utils/model.py`](utils/model.py) — связь \(f=0{,}5x^2+y^2+0{,}5xy-4y\), тяжесть, вязкое трение). Теоретическая траектория считается **одним** прогоном **RK4** с шагом `dt` из формы. К ней добавляется шум; по \(N\) реализациям строятся среднее и **двусторонний 95% доверительный интервал** для среднего по **распределению Стьюдента** (\(df=N-1\)).

## Формулы (для отчёта)

**Экспериментальная траектория** (индекс по времени \(i\), номер реализации \(k\)):

\[
x^{\mathrm{exp}}_{k,i} = x^{\mathrm{th}}_i + \xi^x_{k,i}, \quad
y^{\mathrm{exp}}_{k,i} = y^{\mathrm{th}}_i + \xi^y_{k,i}.
\]

**Накопленный шум** (для каждой координаты и каждого \(k\) свой генератор):

\[
\xi_{i} = \xi_{i-1} + \zeta_i, \quad \xi_0 = \zeta_0,
\]

где \(\zeta_i \sim \mathcal{N}(0, \sigma^2)\) независимы (в коде — `numpy.random.Generator.normal`).

**Выборочное среднее** в момент \(i\):

\[
\bar{x}_i = \frac{1}{N}\sum_{k=1}^{N} x^{\mathrm{exp}}_{k,i}.
\]

**Несмещённая выборочная дисперсия** и **СКО**:

\[
s_{x,i}^2 = \frac{1}{N-1}\sum_{k=1}^{N} (x^{\mathrm{exp}}_{k,i} - \bar{x}_i)^2, \quad s_{x,i}=\sqrt{s_{x,i}^2}.
\]

**95% двусторонний ДИ** для \(\bar{x}_i\) при неизвестной дисперсии:

\[
\bar{x}_i \pm t_{1-\alpha/2,\,N-1}\,\frac{s_{x,i}}{\sqrt{N}}, \quad \alpha = 0{,}05.
\]

Квантиль \(t\) — `scipy.stats.t.ppf(1 - α/2, df=N-1)`. Для \(y\) — аналогично.

## Интерфейс

- Параметры модели, начальные условия, \(t_{\mathrm{start}}\), \(t_{\mathrm{end}}\), шаг **dt** для RK4.
- Блок **«Эксперимент»**: \(N \in \{5,\,25\}\), **σ** шума, **seed** для воспроизводимости.
- Кнопка запуска строит: все экспериментальные траектории на \(xy\), теорию и среднее; графики \(x(t)\), \(y(t)\) с заливкой ДИ.
- Анимация — по **средней** траектории.
