# Лабораторная работа 3 — расширенный фильтр Калмана (EKF)

Модель движения точки по связи \(f = 0{,}5x^2 + y^2 + 0{,}5xy - 4y\) с тяжестью и вязким трением — как в ЛР1 (`utils/model.py`). Состояние \(\mathbf{x} = [x, y, v_x, v_y]^T\).

## Алгоритм (блок-схема)

```mermaid
flowchart LR
  subgraph gen [Данные]
    RK4[RK4 теория]
    Noise[Одна шумовая траектория]
    RK4 --> Noise
  end
  subgraph ekf [Цикл EKF]
    Pred[RK4 предсказание x, P]
    Upd[Калмановское обновление]
    Pred --> Upd
  end
  Noise --> Upd
  Draw[Графики x(t), y(t)]
  Upd --> Draw
```

1. Интегрирование ОДУ методом RK4 с шагом \(\Delta t\) — «идеальная» траектория \((x_k^{\mathrm{th}}, y_k^{\mathrm{th}})\).
2. К той же сетке времени добавляется **накопленный** гауссов шум по \(x\) и \(y\) (как в ЛР2): одна реализация с заданными `seed` и \(\sigma\).
3. По ряду измерений \(\mathbf{z}_k = [x_k^{\mathrm{exp}}, y_k^{\mathrm{exp}}]^T\) выполняется EKF; \(\Delta t\) совпадает с шагом интегрирования.

## Формулы EKF

**Предсказание** (один шаг дискретизации совпадает с одним шагом RK4 для той же правой части):

\[
\hat{\mathbf{x}}_{k|k-1} = \boldsymbol{\Phi}(\hat{\mathbf{x}}_{k-1|k-1}),\quad
P_{k|k-1} = F_{k-1} P_{k-1|k-1} F_{k-1}^T + Q,
\]

где \(\boldsymbol{\Phi}\) — отображение «один шаг RK4», \(F_{k-1} = \left.\partial \boldsymbol{\Phi}/\partial \mathbf{x}\right|_{\hat{\mathbf{x}}_{k-1|k-1}}\) (в коде — **численный** якобиан по четырём компонентам состояния).

**Обновление** (линейная модель измерений \(h(\mathbf{x}) = H\mathbf{x}\), \(H = \begin{bmatrix}1&0&0&0\\0&1&0&0\end{bmatrix}\)):

\[
\mathbf{S}_k = H P_{k|k-1} H^T + R,\quad
K_k = P_{k|k-1} H^T \mathbf{S}_k^{-1},
\]

\[
\hat{\mathbf{x}}_{k|k} = \hat{\mathbf{x}}_{k|k-1} + K_k(\mathbf{z}_k - H\hat{\mathbf{x}}_{k|k-1}),\quad
P_{k|k} = (I - K_k H) P_{k|k-1}.
\]

**Начальные условия фильтра:** \(\hat{\mathbf{x}}_{0|0} = (x_0, y_0, v_{x0}, v_{y0})^T\) из полей формы (вариант по умолчанию: \(0, 4, 0, 0\)); \(P_{0|0} = p_0^2 I\) (поле `p₀`).

**Шумы:** \(R = \mathrm{diag}(\sigma_{rx}^2, \sigma_{ry}^2)\); \(Q = q_{\mathrm{scale}}^2 I_4\). Параметры подбираются ползунками; разумно согласовать \(\sigma_{rx}, \sigma_{ry}\) с масштабом шума траектории \(\sigma\).

**Замечание для отчёта:** в ЛР2 накопленный шум по координатам **коррелирован во времени**; классический Kalman для измерений предполагает **белый** шум. В учебной постановке \(\mathbf{z}_k\) трактуются как «грязные измерения»; \(R\) и \(Q\) подбирают так, чтобы фильтр визуально сглаживал траекторию — это осознанное упрощение модели.

## Интерфейс

| Поле | Назначение |
|------|------------|
| g, b, m | Параметры модели (тяжесть, трение, масса) |
| x₀, y₀, vₓ₀, vᵧ₀ | Начальные условия (на связи и с касательной скоростью) |
| t нач., t кон., Δt | Интервал и шаг RK4 (= шаг EKF) |
| σ, seed | Гауссов шум накопления по x и y для одной эксп. траектории |
| σ_rx, σ_ry | Диагональ \(R\) (дисперсии измерений по x и y) |
| q_scale | Масштаб \(Q = q^2 I\) |
| p₀ | Масштаб \(P_0 = p_0^2 I\) |

Окно: **«ЛР3 — EKF»**. Графики: **x(t)** и **y(t)** — три кривые (теория, эксперимент, EKF).

## Проверки

- При \(\sigma \to 0\) и малом \(q_{\mathrm{scale}}\) отфильтрованная кривая близка к теории и к измерениям.
- При умеренном шуме фильтр обычно **глаже** эксперимента и ближе к теории, чем сырой шум (качественно по графику).

При нестабильности численного якобиана или расходимости \(P\) уменьшите \(\Delta t\) или скорректируйте \(Q\), \(R\), \(p_0\).
